# Changelog

Todos los cambios importantes de este proyecto se documentan en este archivo.

## [0.2.0] - 2026-08-28

### Agregado

- Gestión de imágenes de galería mediante API y almacenamiento de Vercel Blob.
- Carga, listado y eliminación de imágenes desde el panel de administración.

## [0.1.0] - 2026-08-12

### Agregado

- Estructura inicial del sitio y componentes base de la web.
- Nuevas secciones de galeria, ubicacion y precios.
- Navegacion responsive con menu movil.
- Integracion de contacto por Instagram.

### Cambiado

- Ajustes de titulos y enlaces de navegacion en componentes de la home.
- Configuracion de despliegue en Vercel.

### Corregido

- Correccion de navegacion al hacer clic en el logo.
- Correccion de datos de contacto telefonico.
